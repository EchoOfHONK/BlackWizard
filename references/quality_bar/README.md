# Shattered Sanctum — Quality Bar

This folder contains the **visual acceptance target** for the current UE5 vertical slice.

Codex must treat these boards as a quality bar, not as production assets to crop or copy literally.

## Required visual outcome

The playable slice must communicate:

- dark-fantasy gothic ruins with real 2.5D depth;
- high-fidelity pixel-art character presentation against real-time UE5 environment layers;
- strong silhouette readability;
- black / charcoal / ash / crimson base palette with cold lightning accents;
- atmospheric fog, rain/ash, fire, distant storm and deep background architecture;
- readable, compact thematic HUD;
- fast, precise, dangerous combat with strong impact, parry and dash feedback;
- a scene that looks like an early real game, **not** an Unreal tutorial or graybox.

## Rejection criteria

A build is not visually acceptable if it still relies on:

- flat gray floors and primitive blockout architecture as the default presentation;
- empty or flat backgrounds;
- generic placeholder hero/enemy silhouettes;
- debug text dominating the normal HUD;
- lighting that does not create depth or atmosphere;
- VFX that are either absent or visually noisy/unreadable;
- a camera composition that feels like a test harness rather than a finished side-view action game.
