# UE5 Concept Art Regeneration Prompts

These prompts define how to regenerate the old concept sheets specifically for the Unreal 2.5D direction. Do not imitate a single copyrighted game's exact style, characters or UI.

## 01 — Core gameplay key art

Create a high-fidelity pixel-art/2.5D dark fantasy gameplay concept for Shattered Sanctum. Side-scrolling composition, hooded protagonist on the gameplay plane, crisp pixel silhouette, tattered black/bone cloth, sword, white branching lightning. Behind him: deep 3D ruined cathedral layers, red stained-glass glow, chains, fog, rain, ash, monumental negative space. Foreground silhouettes create depth. Palette near-black, charcoal, bone, controlled crimson, hard white electricity. Show subtle Unreal-like volumetric atmosphere and local lightning illumination while preserving sharp pixel edges. No photorealistic hero, no glossy generic fantasy, no copied characters/logos.

## 02 — Environment sheet

Create four side-view 2.5D environment concepts for the same game: shattered sanctuary, storm tower, ossuary catacombs, cursed battlements. Each panel shows a clear 2D traversal plane plus layered 3D foreground/midground/background architecture, fog and weather. Pixel-art gameplay surfaces remain crisp while distant architecture has real depth and lighting. Gothic sacred ruin, chains, cages, bone, corroded iron, broken bridges, red ritual windows, white storm flashes. Include no text other than small neutral panel numbers.

## 03 — Character animation / presentation sheet

Create a clean high-fidelity pixel character design sheet for the hooded protagonist, consistent scale and silhouette, with key poses for idle, run, jump, dash, sword Light 1/2/3, parry, riposte, Lightning Hand, Thunder ground-to-sky cast, wall run, ledge grab and Lightning Glide. Also show separate Unreal presentation layers: base body sprite, weapon sprite, chest artifact, back artifact, lightning VFX overlay. Dark neutral background, no decorative prose.

## 04 — Artifact sheet

Create three canonical artifact concepts only: Heart of the Storm chest relic, Broken Seraph back-wing reliquary, Thunder Spine back attachment. For each show standalone object, equipped front/back character view, emissive/electrical state and simplified attachment silhouette readable at gameplay scale. Bone, iron, cloth, crimson ritual marks, white electricity. No extra relics.

## 05 — Enemy sheet

Create five original role silhouettes: Melee Zealot, Ranged Penitent, Shield Guardian, Elite Executioner and a storm mini-boss. High-fidelity pixel characters designed for side-view readability; each has a distinct weapon/body mass. Ruined sacred gear, bone/iron/cloth, controlled red accents. Mini-boss uses halo/reliquary geometry and white lightning. Include one telegraph pose per enemy. No copied designs.

## 06 — UI sheet

Create a readable dark ritualistic 16:9 game HUD/UI concept: HP, Stamina, Mana, Storm Warning, current weapon, exactly two artifact slots, combo counter and boss bar. Thin distressed bone-gray frames, controlled crimson selection/danger, sparse ritual geometry, black transparent panels. Must remain readable over a dark 2.5D game scene; avoid excessive grunge over numerical data.

## 07 — Combat screenshot target

Create a single 16:9 side-scrolling gameplay screenshot target for Shattered Sanctum in a 2.5D Unreal-like presentation: crisp pixel protagonist and enemies on a fixed plane, detailed 3D gothic ruins receding in depth, foreground chains, volumetric fog/rain, Chain Lightning connecting enemies, Thunder Pillar erupting upward, subtle bloom/local light, debris and shockwave, HUD visible but restrained. The image must look like a playable game, not a poster.
