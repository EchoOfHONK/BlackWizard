# Unreal Content Naming

Project prefix: `BW` for native C++ classes, standard Unreal asset prefixes for content.

## C++

- `ABWPlayerCharacter`
- `UBWCombatComponent`
- `UBWArtifactComponent`
- `UBWAttributeSet`
- `FBWDamageSpec`

## Assets

- Levels: `L_CombatLab`
- Blueprint actors: `BP_*`
- Widgets: `WBP_*`
- Input Actions: `IA_*`
- Input Mapping Contexts: `IMC_*`
- Gameplay Abilities: `GA_*`
- Gameplay Effects: `GE_*`
- Gameplay Cues: `GC_*`
- Primary Data Assets: `PDA_*`
- Niagara Systems: `NS_*`
- Niagara Emitters: `NE_*`
- Materials: `M_*`
- Material Instances: `MI_*`
- Textures: `T_*`
- Paper Sprites: `SPR_*`
- Flipbooks: `FB_*`
- Static Meshes: `SM_*`
- Sound Cues/MetaSounds: `SC_*` / `MS_*`

Keep paths and names ASCII-only to reduce toolchain friction.
