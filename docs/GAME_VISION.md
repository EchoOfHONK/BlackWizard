# Shattered Sanctum — Game Vision

Status: **Canonical**  
Version: **2.0 — Unreal 2.5D revision**

## High concept

Shattered Sanctum is a dark **2.5D Action Roguelite** with Souls-like combat elements, advanced platforming and a strong build identity. The player combines weapons, Lightning, Thunder, parries, dodges, parkour and two visible artifacts into fast technical combat sequences.

The game preserves a side-scrolling gameplay plane while Unreal Engine provides layered 3D architecture, atmosphere, lighting, materials and Niagara VFX around high-fidelity pixel characters.

The player should flow between systems without artificial pauses:

`Weapon -> Magic -> Dash -> Parry -> Counter -> Launcher -> Air Combo -> Thunder -> Reposition`

## Reference direction

- Blasphemous 1 & 2 — oppressive sacred ruin, grotesque silhouettes, detailed pixel sensibility.
- Dead Cells — responsiveness, readable roguelite combat, fluid chaining and fast traversal.
- Mortal Shell / Mortal Shell II — corroded dark fantasy, body horror, weight, decay and monumental material language.

These are directional references only. Do not copy characters, maps, UI layouts, names or proprietary assets.

## Core pillars

### Technical Combat
Combat is fast, readable and dangerous. Mastery comes from timing, spacing, parry, dodge, cancel windows, enemy knowledge and combining systems.

### Lightning
Lightning is the protagonist's primary magic school: fast, precise, violent, branching and combo-friendly.

### Thunder
Thunder is a Lightning sub-school focused on AoE, crowd control, launch, stagger and shockwaves. Its signature language is **ground-to-sky / bottom-to-top**.

### Mobility
Movement is part of combat: wall interaction, ledge grabs, double jump, ground/air dash and Lightning Glide must blend with attacking and casting.

### Artifacts
Exactly **two artifacts** may be equipped. Artifacts alter stats/rules/abilities and must **always visibly alter the character**.

## Storm Warning
Aggressive and skillful play fills a dedicated Storm Warning meter. At maximum, the character becomes electrically charged for a limited time and gains greatly increased Shock/Stagger pressure.

Regular enemies can be stunned aggressively; elites recover more quickly; bosses cannot be permanently stun-locked.

## Weapons
Vertical slice:
- Sword — fast universal melee, parry/riposte oriented.
- Staff — slightly slower, block/deflect oriented, strong Lightning synergy.

Future architecture must support spear, daggers, chains and other weapon families without rewriting the player.

## Roguelite loop
`Sanctum/Hub -> Preparation -> Run -> Combat/Traversal -> Temporary Power -> Elite/Events -> Boss -> Death or Victory -> Permanent Progression -> New Run`

World routes should be assembled from high-quality handcrafted sections, not generic anonymous procedural rooms.

## Visual target
**High-fidelity pixel characters inside a deliberately layered 2.5D Unreal world.**

- near-black/charcoal masses;
- dirty gray, dark iron and old bone;
- deep crimson as controlled accent;
- white/pale electrical flashes used sparingly;
- ruined sacred architecture, chains, reliquaries, corroded metal, banners and bone;
- 3D fog, rain, ash and depth layers;
- Paper 2D characters with crisp nearest-neighbor treatment;
- Niagara lightning/thunder that tears through darkness without destroying combat readability.

## One-line definition
**A dark high-fidelity pixel-art 2.5D roguelite where Souls-like precision meets extreme responsiveness, deep weapon combat, parkour and storm magic built for continuous technical combos.**
